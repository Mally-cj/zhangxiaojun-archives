# 张小珺商业访谈录 · 书籍化项目

将《张小珺商业访谈录》播客的长篇深度访谈转化为商业传记书籍章节，以"纸上的深度纪录片"形式还原商业社会的真实刀光剑影与创业者的第一手洞见。

## 项目结构

```
张小珺商业访谈录/
├── README.md           # 项目说明
├── 原文/               # 播客转录原始稿件
└── 书籍章节/           # 加工后的书籍章节（HTML，可浏览器打开或打印为PDF）
```

## 写作原则

- **完整性压倒一切**：保留受访者所有逻辑推演、论点论据及背景细节，严禁概括或删减
- **真实性优先**：修正ASR同音错别字但严禁改变原话本意，保留受访者"肌肉记忆"式的原始表达
- **拒绝平庸总结**：通过重组对话让读者看到人物如何一步步推演出结论
- **严禁文学化编造**：所有张力来自对话本身、思想交锋和事实陈述

## 格式规范

- 每章开头包含：章节标题、核心关键词、播客标题、嘉宾引言
- 纯长文叙述，禁止小标题和列表
- 英文/数字使用 Baskerville，中文使用思源宋体
- 象牙色纸张质感（`#fdfaf2`），每页底部标页码
- 每页约2000-3000字，总篇幅20-30页
