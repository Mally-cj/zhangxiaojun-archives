# 张小珺商业访谈录 · 纸上纪录片

将《张小珺商业访谈录》播客的长篇深度访谈转化为适合手机/网页阅读的书籍章节，以"纸上的深度纪录片"形式还原商业社会的真实刀光剑影与创业者的第一手洞见。

## 为什么做这个？

纯粹为了**方便自己阅读**。播客是很棒的媒介，但信息密度太高——开车、走路、做家务的时候听，很难真正消化那些层层递进的逻辑推演和精确的商业判断。把一场访谈变成一篇可以随时翻阅、反复咀嚼的"书本章节"，是我自己最舒服的消费方式。

**这是个人项目，非商业用途。所有内容版权归《张小珺商业访谈录》及其工作室"语言及世界"所有。**

## 制作流程

```
播客音频 → 通义听悟（语音转文字）→ Claude Code（按 prompt 加工为书籍章节）→ HTML 网页
```

1. **通义听悟**：将播客音频转为文字转录稿
2. **人工初审**：核对关键人名、公司名、术语，修正明显的 ASR（语音识别）错误
3. **Claude Code**：按照下方 Prompt 将转录稿加工为书籍章节 HTML
4. **人工复核**：校对专有名词，检查排版效果

## 使用的 Prompt

```
# 角色与使命
你是一位顶尖的非虚构作家和深度传记写手（风格参考《史蒂夫·乔布斯传》或《激荡三十年》）。你的任务是将《张小珺商业访谈录》的一集长篇深度访谈，转化为一本商业传记书籍中的核心章节。执行一场"**纸上的深度纪录片记录稿**"：通过文字还原商业社会真实的刀光剑影、创业者背后最真实的思考起伏，以及那些未经修饰、带有颗粒度的第一手洞见。

---

## 核心指导原则：真实性与完整性（最高优先级）
1.  **完整性压倒一切**：保留受访者所有的逻辑推演过程、论点论据及背景细节。严禁任何形式的概括、浓缩或删减。
2.  **专有名词与事实校验**：
    *   身份校验：准确识别受访者姓名，并在全文中统一使用正确的汉字，严禁出现语音转录（ASR）中常见的同音错别字。
    *   术语校准：严格核对本访谈涉及的商业与技术专有名词。包括但不限于：公司名、产品名、行业术语、英文缩写及特定的商业概念，确保拼写及上下文逻辑准确。
    *   逻辑修正：识别并修正语音转录中的同音错别字（如将"投后"误写为"投厚"），但在修正时严禁改变受访者的原话本意。
3.  **回归真实的表达与脉络**：原封不动地保留受访者具有"肌肉记忆"的原始表达（包括特定的比喻、口头禅、非标词汇、自嘲等）。仅去除纯粹的口语填充词（如"那个"、"呃"）。禁止重写或美化受访者的语气。
4.  **拒绝平庸的总结**：禁止写"他们讨论了人工智能的未来"这种总结性语句。必须通过重组对话，让读者看到人物如何一步步推演出结论。
5.  **严禁文学化编造**：严禁编造原稿中不存在的环境描写、人物动作、神态描写及心理状态臆测。所有的张力必须来自于对话本身、思想的交锋和事实的陈述。

---

## 写作结构要求
1.  **每一章的固定开头格式**
    每一章的第一页必须包含以下四个元素，严禁遗漏：
    *   **题目**：具有传记质感的章节大标题。
    *   **核心关键词**：提取本章最核心的1-2个商业/技术关键词。
    *   **播客标题**：注明原始播客的完整题目。
    *   **嘉宾引言（Quote）**：摘录一段嘉宾最具冲击力或最能代表本章精神的原话。
2.  **禁止小标题**
    *   纯长文叙述：章节内部禁止使用任何形式的小标题、副标题或小章节划分。
    *   禁止列表：严禁使用项目符号（Bullet Points）或数字列表。
    *   段落衔接：通过逻辑自然推进，段落之间空一行，体现纪录片的"剪辑感"与连贯性。

---

## 写作流程细则
*   **场景化还原**：必须从访谈中最具张力的时刻、深刻的问题或受访者当时的心境切入，迅速带入纪录片的临场感。
*   **保留互动张力**：完整保留张小珺具有拆解性、追问性甚至攻击性的原始提问，展现真实的商业交锋。
*   **人物刻画与关系**：第一次提到某个名字（投资人、对手、合伙人）时，用1-2句极其传神的话介绍其身份及重要性。通过原语呈现受访者的真实状态（焦虑、狂妄、理性的肌肉记忆）。
*   **专业概念的"耳边批注"**：针对技术术语或行业黑话，在第一次出现时利用嘉宾原话自然揉进叙事。要求短小精悍，像作者在耳边的轻声批注，而非教科书定义。
*   **真实性校验**：严禁删除访谈末尾提到的生活细节（如健康建议、饮食偏好等），这些是体现"人"的真实性的核心。

---

## 最终成品排版规范
1.  **书籍质感排版**：
    *   每页文字必须铺满（约2000-3000字）。
    *   英文/数字使用 **Baskerville** 字体，中文使用衬线宋体（思源宋体）。
    *   模拟象牙色纸张质感（`#fdfaf2`）。
    *   每页底部正中标明页码（如 `- 1 -`）。
2.  **篇幅要求**：总篇幅必须根据原稿深度扩展至20-30页，确保每一页的信息密度。
```
